# Working Principle

The blood pressure cuff is connected to a pressure sensor.

The pressure sensor detects changes in cuff pressure and provides an electrical signal to the Arduino.

The Arduino reads and processes this signal. The processed data can be used to estimate blood pressure and pulse rate.

The results can then be displayed on an OLED display and monitored through the Serial Monitor.

The system is intended as an educational prototype for understanding Arduino-based health monitoring.
